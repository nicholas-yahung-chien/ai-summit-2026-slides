# 設計與交付規劃

## 目標

10/23 AI 高峰會。保留參考簡報的固定畫布、清楚敘事與版型節奏，以 Slidev 提供成熟的播放、講者與編輯框架。
本次交付可直接線上檢視的設計樣稿、repo、GitHub Actions 與 Pages，安裝官方 Skill 並驗證 MCP。

## 視覺

- 1280×720 設計畫布，16:9 等比例播放。
- IBM Blue 60 `#0f62fe` 作為品牌重點；Blue 70 `#0043ce` 作為藍底／小字；Blue 90 `#001d6c` 作為結尾背景。
- 正文 `#161616`／背景 `#f4f4f4`；說明 `#525252`。正文 27–32px（1920px 投影等比例約 40.5–48px），標題 58–108px。
- 依提供主視覺參考青綠與淡紫；僅作圖形和章節點綴，不使用淡色正文。
- 英文 IBM Plex Sans，中文 Noto Sans TC；字體本機打包。
- 以原創 SVG 表現層疊帶狀節奏；不冒充主視覺的原始 logo。
- 使用簡短 fade，支援 reduced motion。

參考：<https://www.ibm.com/design/language/color/>

## 互動與驗證

- 直接輸入頁碼；阻擋空白、非整數與超出範圍。
- hash 網址支持指定頁與重新整理。
- 使用 Slidev 共用 timer，避免講者模式與主頁有兩個不一致的時鐘；預設 30 分鐘可在 headmatter 修改。
- 計時開始、暫停、續計、重設；超時可辨識。
- 講者模式包含下一頁與公開樣稿備註。
- 驗證全部頁面、操作控制、瀏覽器載入錯誤、正式 base 路徑與線上建置。
